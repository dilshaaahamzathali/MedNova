# MedNova – Privacy-Focused Healthcare Web Application

MedNova is a web-based healthcare application designed to support privacy-aware interaction between patients and verified doctors.

## Main Features
- Patient and doctor registration
- Doctor verification
- Online consultation management
- Patient support communities
- Community post moderation
- Security audit logging

## Project Structure

- `backend/` – Django backend, application modules, and database
- `frontend/` – HTML, CSS, JavaScript, and images
- `backend/authentication/` – Authentication and user profiles
- `backend/consultations/` – Consultation management
- `backend/communities/` – Patient communities and discussions
- `backend/articles/` – Healthcare articles

## Technologies Used
- Python and Django
- SQLite
- HTML, CSS, and JavaScript

## Project Status
This project is being developed as part of an academic MCA project.
